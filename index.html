Supported formats

Word: DOCX, DOCM, DOTX, DOTM

PowerPoint: PPTX, PPTM, POTX, POTM, PPSX, PPSM

OpenDocument: ODT, OTT, ODP, OTP, ODS, OTS

Rich Text: RTF

What does it change?

Only the proofing-language metadata you explicitly repair. Language Doctor does not rewrite your document text. Smart Fix preselects only high-confidence safe suggestions.

Privacy

Document contents, filenames and file bytes stay on your device. There is no upload endpoint, account system or server-side document processing.
