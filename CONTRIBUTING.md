# Contributing

Office Language Doctor is developed and maintained by NeoRS.

The official repository currently **does not accept external code contributions or pull requests**.

You can still help the project by opening an Issue for:

- reproducible bugs;
- document compatibility problems;
- false-positive or false-negative language detection;
- feature proposals;
- accessibility or usability problems;
- documentation corrections.

Please do not include confidential documents or sensitive personal information in an Issue. Use a minimal synthetic sample whenever a file is required to reproduce a problem.

The project remains open source under MPL-2.0 from v0.5.0 onward. This contribution policy does not restrict the rights granted by that license to fork, modify or redistribute the covered source.
